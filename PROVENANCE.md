# Provenance and evidence boundary

Created on 13 October 2026 as a new educational showcase for Sourodeep Kundu. Code and visual design were created with Codex assistance, rather than extracted from an employer repository or another person's GitHub projects.

The implemented protocol follows standard ideal teleportation: Bell pair preparation, sender CNOT/H, two measurement bits, receiver conditional X/Z. Routing is a documented BFS-based greedy baseline. The tests establish these limited behaviors; they do not establish research novelty, quantum advantage or prior-project authorship.

No private source, patient data, certificates or paid API calls are included. Synthetic circuits and user-selected state angles drive the examples.
